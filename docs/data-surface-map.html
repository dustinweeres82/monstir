🗄️ Monstir — DB ↔ UI Surface Map

15 Supabase tables · what's stored vs. what the user actually sees · 2026-06-20 ← Architecture map
Not everything in the database reaches the screen, and a lot of what the user sees doesn't come from the table you'd expect. Monstir keeps its real source of truth for the chore board, history, OWED, approval calendar and savings goals in JSON blobs on profiles and kids — several normalized tables that look authoritative are actually write-only shadows or orphaned. This map sorts every table by whether it is surfaced to the user, and notes where the real data lives when it isn't.
